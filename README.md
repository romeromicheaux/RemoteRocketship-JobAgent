# Remote Rocketship AI Job Agent

🔗 **[View Project on GitHub](https://github.com/romeromicheaux/RemoteRocketship-JobAgent)**

A Node.js-based job discovery and resume-matching application that uses the Remote Rocketship API to identify and rank relevant remote AI employment opportunities.

## Overview

This project automates parts of the job search process by retrieving remote job listings, filtering opportunities, and comparing job requirements against skills extracted from a resume.

## Key Features

- Retrieves job opportunities through the Remote Rocketship API
- Searches across AI evaluation, response quality, content review, and data annotation roles
- Filters opportunities for U.S.-remote relevance
- Extracts resume text from Microsoft Word documents
- Ranks opportunities using skill-based matching logic
- Displays relevant job opportunities with application links

## Technology Stack

- **JavaScript / Node.js** — Application logic
- **Remote Rocketship API** — Job discovery
- **Mammoth.js** — Word document text extraction
- **Git / GitHub** — Source control and project hosting

## Security

API authentication uses the `REMOTE_ROCKETSHIP_API_KEY` environment variable. API credentials, personal resumes, and installed dependencies are excluded from the repository.
